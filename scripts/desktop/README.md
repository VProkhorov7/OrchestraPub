# Ярлыки для рабочего стола

Копии файлов с рабочего стола владельца (`~/Desktop`), чтобы они не терялись:

- `Orchestra.command` — запускает службу и открывает панель; если служба уже работает, показывает вкладку в Яндекс.Браузере (или открывает новую) и закрывает своё окно Терминала.
- `Orchestra-restart.command` — безопасный перезапуск: не трогает службу, пока идут задачи воркеров.

Путь к репозиторию берётся из переменной `ORCHESTRA_REPO` (по умолчанию `~/Developer/Orchestra`). Чтобы поставить ярлыки: `cp scripts/desktop/*.command ~/Desktop/`, затем при нестандартном пути добавьте в начало файла `export ORCHESTRA_REPO="/путь/к/Orchestra"`.
