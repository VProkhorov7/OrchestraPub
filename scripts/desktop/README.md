# Ярлыки для рабочего стола

Один настоящий файл, `Orchestra.command`, и три переходника на рабочем столе, которые ставит `install.sh`:

| На рабочем столе | Что делает |
|---|---|
| `Orchestra.command` | Запускает службу, если она не работает, и открывает панель в уже открытой вкладке (или в новой). |
| `Orchestra-restart.command` | Перезапускает службу. Пока идут задачи воркеров, не трогает её и спрашивает, перезапускать ли всё равно. |
| `Orchestra-stop.command` | Останавливает службу и не запускает её при входе. |

Служба работает под launchd: стартует при входе в систему и не зависит от окон Терминала. Файл только управляет ею. Он сам пересобирает Orchestra, если изменился код, исправляет файл агента launchd, если папка переехала, и закрывает своё окно Терминала.

Установка: `scripts/desktop/install.sh`. Путь к репозиторию записывается один раз в `~/.orchestra-repo`; если переместили папку, запустите `install.sh` снова. Старые файлы с такими же именами откладываются с суффиксом `.old`.

Из терминала то же делает `orchestra-ctl up | restart [--force] | stop | status | url` (после `npm link`).
