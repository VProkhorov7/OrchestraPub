**Page text**

Orchestra makes an expensive AI model the lead engineer and a few cheap ones its team. You describe a task. Claude (or ChatGPT) plans it, writes briefs and hands them to workers such as DeepSeek, GLM, Kimi or Qwen, each in its own git worktree. It then reads every diff and merges only what passes review.

- **Cheap:** planning and review run on the subscription you already pay for, and the code is written by models that cost 10–50× less.
- **Safe:** every task has its own branch, nothing reaches your main branch unreviewed, and spend caps stop a task while it runs.
- **Visible:** a live overview of each running project, a traffic light for each connection, and the history of every run.
- **Open:** an MCP server lets Claude Code, Codex, Cursor or Orca drive the workers; project memory records what was decided and why.
- **Yours:** runs on your machine or a home server, English or Russian interface, light and dark theme, MIT licence.

**Текст для страницы**

В Orchestra дорогая ИИ-модель работает ведущим инженером, а несколько дешёвых составляют её команду. Вы описываете задачу. Claude (или ChatGPT) планирует её, пишет брифы и раздаёт исполнителям (DeepSeek, GLM, Kimi, Qwen), каждому в свой git worktree. Затем читает каждый diff и сливает только то, что прошло ревью.

- **Дёшево:** планирование и ревью идут по подписке, за которую вы уже платите, а код пишут модели, которые стоят в 10–50 раз дешевле.
- **Безопасно:** у каждой задачи своя ветка, в основную ничего не попадает без проверки, а лимит расхода останавливает задачу прямо во время работы.
- **Наглядно:** живой обзор каждого идущего проекта, светофор для каждого подключения и история всех запусков.
- **Открыто:** MCP-сервер позволяет Claude Code, Codex, Cursor или Orca управлять исполнителями; память проекта хранит принятые решения и их причины.
- **Ваше:** работает на вашем компьютере или домашнем сервере; интерфейс на русском и английском, светлая и тёмная тема, лицензия MIT.
